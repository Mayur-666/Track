# Track

A simple and elegant command-line task tracker to help you manage your daily tasks efficiently. Track what you need to do, what you're working on, and what you've completed - all from your terminal.

## Features

- ✅ Add new tasks with automatic ID generation
- 📋 List all tasks with their current status
- 🎯 Mark tasks as in-progress or done
- 🗑️ Delete tasks you no longer need
- 💾 Persistent storage using JSON
- 🎨 Colorful CLI output for better readability
- ⚡ Fast and lightweight
